# bpscccheck

Página pública de consulta do SCC Check, recriada em HTML, CSS e JavaScript.

## Como abrir

```bash
python3 server.py
```

A página fica disponível em:

- http://localhost:6060/
- http://localhost:6060/consulta

O envio para a API de conversões da Meta usa a variável de ambiente `META_CAPI_TOKEN`. O valor não fica no repositório.
